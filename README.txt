# Flag Battle — versión visual

Abre `index.html` en Safari o en otro navegador moderno.

La aplicación está contenida en un único HTML: incluye HTML, CSS y JavaScript y no necesita librerías externas.

Mecánica:
- 64 banderas.
- Eliminatoria 64 → 16 → 4 → 1.
- Cuatro opciones por grupo.
- Ranking ELO local.
- Ranking por ELO, victorias y porcentaje de victorias.
- Resultado y compartir.
- Diseño mobile-first inspirado en el mockup.
